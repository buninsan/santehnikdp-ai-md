# santehnikdp-ai-md

DIY заміна платних Publii-плагінів "Markdown for AI" + "LLMS.txt Generator" (TidyCustoms). Окремий Cloudflare Worker — не займає жодного файлу в репозиторії, яким керує Publii (той самий принцип, що і з бекендом відгуків: Publii затирає все, що сам не рендерив).

## Що робить

- **`https://santehnik.dp.ua/будь-яка-сторінка.md`** — чиста Markdown-версія сторінки: заголовок, опис, посилання на канонічний URL, і сам текст статті (без шапки, меню, кнопок дзвінка, блоків відгуків/робіт — тільки контент).
- **`https://santehnik.dp.ua/llms.txt`** — індекс сайту: список усіх сторінок (з `sitemap.xml`, який Publii вже генерує сам) + посилання на їхні `.md`-версії. AI-інструменти (ChatGPT, Claude, Perplexity) заходять сюди першими, щоб зрозуміти структуру сайту.

Все рахується "на льоту" при кожному запиті (Cloudflare Worker забирає вже готову `.html`-сторінку з живого сайту і перетворює у Markdown через `HTMLRewriter` — вбудований у Cloudflare інструмент для потокового розбору HTML). Кешується на годину (`cache-control: max-age=3600`), тож зайвого навантаження на origin нема.

## Розгортання (перший раз)

Два варіанти — обери зручніший:

### Варіант А: через GitHub (як з відгуками)

1. Створи новий приватний репозиторій на GitHub, запуш цю папку туди.
2. Cloudflare Dashboard → Workers & Pages → Create → Workers → **Import a repository** → вибери цей репозиторій → Deploy.
3. Далі крок 3 нижче (Routes) — обов'язково, без нього Worker не підключиться до `santehnik.dp.ua`.

### Варіант Б: через CLI (`wrangler`), якщо є Node.js

```bash
cd santehnikdp-ai-md
npm install
npx wrangler login
npx wrangler deploy
```

### Крок 3 (обов'язковий в обох варіантах): підключити Routes до домену

`wrangler.toml` вже містить потрібні Routes (`santehnik.dp.ua/*.md` і `santehnik.dp.ua/llms.txt`) — `wrangler deploy` мав їх підхопити автоматично. Якщо розгортав через GitHub-інтеграцію (Варіант А), перевір і за потреби додай вручну: Worker → Settings → Triggers → Routes → Add route → встав ті самі два патерни, zone = `santehnik.dp.ua`.

Домен `santehnik.dp.ua` вже проксується через Cloudflare (DNS хмаринка помаранчева) — це все, що потрібно для Routes, окремий Cloudflare Pages чи ще щось не обов'язкові.

## Перевірка після розгортання

```
https://santehnik.dp.ua/llms.txt
https://santehnik.dp.ua/avariynyy-vyklyk-santehnika-dnipro.md
```

Перша — має показати текстовий список сторінок. Друга — Markdown-версію конкретної статті. Якщо бачиш 404 чи помилку — скинь текст помилки, розберемось.

## Відомі обмеження v1

- Конвертер написаний вручну під структуру теми "Simple" (знає класи `.works`, `.reviews`, `.cta-call`, `.breadcrumbs` — прибирає їх як "шапку/віджети", лишає тільки сам текст статті). Якщо колись зміниться структура теми (нові блоки, нові класи), можливо, доведеться підправити список прибирання в `src/index.js`.
- Перевірено логічно, але **ще не тестовано на живому сайті** — перший реальний запуск варто перевірити на пари сторінок (звичайна стаття + головна) і показати мені результат, якщо щось виглядає криво.
